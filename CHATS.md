# История чата

## 2026-11-06 — редизайн PrimeBypass

**Запрос:** полностью переделать дизайн в стиле Prime (vpn.sphereprime.ru) и перепроверить функционал.
**Сделано:** палитра Prime (графит + оранжевый #ff6a35, Inter и JetBrains Mono), перекраска старых экранов.

**Запрос:** переделать не только цвета, а целиком раскладку и удобство.
**Сделано:**
- Оболочка: верхняя шапка с навигацией-таблетками и общим индикатором состояния; на узком экране навигация внизу.
- Обход: большая кнопка питания, профили слева, журнал и параметры справа.
- Разблокировка: каталог с тумблерами и прилипающая панель изменений hosts.
- Проверка: выбор доменов чипами, результаты справа, кнопка «Включить профили для заблокированных».
- Анализ лога: источник и сводка рядом, таблица соединений ниже.
- DNS: вкладки «Обзор / Сверка / Каталог».
- Telegram: кнопка питания, ссылка и счётчики в одном блоке.
- Код разнесён по папкам `components/<страница>`, `ui`, `shell`, `hooks`, `data`, `styles/pages`.

**Запрос:** чтобы одна кнопка сама всё включала: и Telegram, и YouTube, и остальное.
**Сделано:** режим «Авто» по умолчанию. Кнопка проверяет сервисы, включает профили для заблокированных, запускает движок и поднимает прокси Telegram. Есть переключатели «Авто / Вручную» и «Прокси Telegram». Индикатор в шапке показывает обход и Telegram.

**Проверка функционала:** все API ядра отвечают. Через интерфейс проверены: профили, hosts (предпросмотр и подтверждение без записи), анализ лога, проба и сверка DNS, каталог, прокси Telegram (вкл/выкл), проверка доменов, автозапуск. Запуск движка без прав администратора даёт понятную ошибку.
**Исправлено в ядре:** прокси Telegram не мог сохранить конфиг — не создавался каталог `primebypass` (`tg_api.rs`).
