# Порядок переноса (continuation guide, не редактировать без нужды)

diagnostics перенесены ЦЕЛИКОМ, включая engine.py (Run/Lane/Live/Steps, run_probes/recheck_failed, run_blockcheck/run_dns_check/check_site), сетевой транспорт без TLS — net_transport.rs (TCP/STUN/UDP-серии + планировщики + транспорты под EngineIo; golden STUN/шапки + живые локальные тесты) — и TLS/HTTPS-слой: chrome_https.rs дополнен транспортом ChromeConnection/chrome_get на rustls (заголовки WINDOWS_HEADERS, HTTP/1.1 keep-alive, ошибки → коды libcurl, decode_body: gzip/deflate; golden `_classify`/`_cert_problem` против python, 23 случая, + живые локальные тесты — tests/chrome_https_tests.rs). Отпечаток приветствия rustls браузерный не повторяет (python — curl_cffi/BoringSSL): осознанное различие, выводы опираются только на KIND_*/STAGE_*/body_cut. Провайдер шифрования — ring, выбирается явно (иначе rustls падает при неоднозначности ring/aws-lc-rs; ring проще для Windows-сборки). Дымовой тест tests/engine_smoke.rs гоняет полный прогон на подставном транспорте; живой сбор — tests/net_transport_tests.rs на локальных сокетах. Транспорты поверх chrome_get готовы: cause (tls_hello/http_probe через rustls с NoVerify, шаг проб через Run), protocols (TLS 1.2/1.3 + порт 80), volume (запросы по одному Chrome-соединению), cert_owner (tls_stream ANY → peer_certificates()[0] → cert_reader.rs, ручной DER-парсер с BMPString=UTF-16BE; CertCollect возвращает Option), clock_skew (DoH → /generate_204 → свой разбор Date, эталоны против python parsedate_to_datetime, включая високосные 2000/2024 и невисокосный 1900), network (trace по 1.1.1.1, владелец через DoH, local_address через UDP-сокет), freeze (64 КБ c FREEZE_READ_TIMEOUT, кэш адресов; отправка в нём пока не подключена — нужен транспорт http2_post). Фабрики: cause_transport/protocols_transport/volume_transport/cert_transport/chrome_get_transport/clock_skew_transport/network_transport/freeze_transport в net_transport.rs; совместимость типов с EngineIo проверяется тестом transports_wire_into_engine_shapes. Важные гочи: trait-object аннотация `'_` подразумевает 'static — сроки жизни замыканий поверх `&Run` оформлять хелперами с явным `'r`; Lookup IP-владельца принимает FnMut (замыкание с MutexGuard — FnMut); закрытие сервером без ответа в объёме — код 52 → RUN_RESET (как у python). QUIC-слой готов: quic_initial.rs (AES-128/GCM/HKDF руками, golden против python с подменой os.urandom — пакет целиком для 5 имён) + quic_probe::quic_hello (UDP с отменой) + net_transport::quic_collect_with/quic_transport (python collect с параллельными посылками через Run); живые тесты на подставном QUIC-сервере — tests/quic_probe_tests.rs. OS-слой Windows — платформенный (SystemReader-трейт с NullSystemReader для не-Windows).
